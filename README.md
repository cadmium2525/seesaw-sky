# SAND FLAG BATTLE

**たくさん取れ。でも、旗を倒すな。**

砂山の頂上に立つ旗を倒さないように、交互に砂を奪い合う 3D 対戦ゲームです。
素手・スコップ・シャベル・ショベルカーを使い分け、狙う場所・掘る量・崩落のリスクを読み合います。
ブラウザだけで遊べます（インストール不要・スマホ / PC 対応）。

▶ 公開URL: https://cadmium2525.github.io/seesaw-sky/

## 遊び方

| 操作 | スマホ | PC |
| --- | --- | --- |
| 掘る場所を選ぶ | 1本指でタップ（なぞって調整） | クリック |
| 視点の回転・拡大 | 2本指 | ドラッグ・ホイール |
| 掘る | 「掘る」ボタン | 「掘る」ボタン / Space |
| 道具の切り替え | 道具ボタン | 道具ボタン / 1〜4 キー |

- **CPUと対戦**：あなた（先攻）と CPU が交互に1回ずつ砂を取ります。CPU の強さは「よわい／ふつう／つよい」から選べます。同じ端末で2人対戦もできます。
- 掘ったあと砂が崩れ、旗が傾くことがあります。
- **旗を倒した人はその場で負け。** 旗を守りきったら、獲得した砂の量（L）が多い方の勝ち。
- 最大ターン（合計30手）・双方パス・砂がほぼ無くなった時点で終了します。
- ひとりで練習：15手以内でどれだけ取れるか。旗を倒さずに「終了する」と端末内ベストに記録されます。

| 道具 | 掘削量 | 特徴 |
| --- | --- | --- |
| 素手 | 小 | 細かい微調整、低リスク |
| スコップ | 小〜中 | 範囲を調整して縁から安全に稼ぐ |
| シャベル | 中 | 角度と深さを調整。効率と危険のバランス |
| ショベルカー | 大 | アームの引き量を調整。大量獲得、崩落の危険大 |

道具は何回でも使えます。旗がどれだけ危ないかは数値やゲージでは表示されないので、旗の傾きや砂の崩れ方から読み取ってください。

## 仕組み

- **砂山**：129×129 の高さマップ。掘削は範囲内の砂の体積を差し引き、スコアは実際に取り除いた体積だけを数えます（崩れただけの砂は加算しません）。
- **崩落**：傾斜が安息角（35°）を超えた所から周囲へ砂を流すセルオートマトン。全セルの流出量を先に計算してから反映するので処理順に依存せず、砂の総量は保存されます。変化のあった範囲だけを計算して軽くしています。
- **旗**：根元周辺の砂の埋まり具合を同心円状にサンプルし、支持率と傾きを計算。支えを失うと倒れ始め、途中から [Rapier](https://rapier.rs/) の剛体として砂の地形（heightfield）の上を転がります。
- **CPU**：候補手をいくつか作り、取れる量の多い順に「砂山のコピーで実際に掘って崩落させ、旗が倒れないか」を試算して、安全と判断した手を選びます。強さによって候補の数・安全の余裕・安定度の読み違いの大きさが変わります（よわいCPUは読み違えて旗を倒すことがあります）。思考は毎フレーム少しずつ進めるので画面は止まりません。
- **公平性**：初期の砂山は固定シードで生成し、全員が同じ条件で遊べます。ただし端末・浮動小数点・操作の違いがあるため完全な一致は保証しません。記録は端末内のみの非公式記録です。
- **共有**：結果画面でスクリーンショット入りの結果カード（1200×630）を作り、Web Share API で共有。非対応の環境ではテキストをコピーし画像を保存します。自動投稿や SNS 認証は行いません。

調整値（砂山の大きさ、安息角、旗の倒れやすさ、ターン数など）は `src/config.ts` にまとめています。

## 開発

```bash
npm ci
npm run dev      # 開発サーバー http://127.0.0.1:5173/seesaw-sky/
npm test         # ゲームロジックのテスト
npm run build    # dist/ に静的ファイルを出力
```

```
src/
  main.ts                 起動
  config.ts               調整値
  game/Game.ts            進行（入力 → 掘削 → 崩落 → 旗判定 → 手番交代）
  game/Match.ts           ルールと勝敗判定（描画に依存しない）
  game/CpuPlayer.ts       CPU の思考
  terrain/SandField.ts    高さマップ・掘削・崩落
  terrain/SandMesh.ts     砂山の描画
  physics/FlagSupport.ts  旗の支持判定
  physics/FlagSystem.ts   旗の描画と転倒（Rapier）
  tools/DigTools.ts       道具の定義と掘削範囲
  tools/ToolModels.ts     道具・ショベルカー・バケツの3Dモデルとアニメーション
  scene/Stage.ts          レンダラー・カメラ・光源・背景
  fx/Particles.ts         砂粒の演出
  audio/Sfx.ts            効果音（Web Audio で合成）
  ui/Hud.ts               画面表示
  share/ResultCard.ts     結果カードと共有
  storage.ts              端末内保存（設定・ベスト記録）
```

## 公開（GitHub Pages）

`main` へ push すると GitHub Actions がテスト → ビルド → GitHub Pages へデプロイします。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
リポジトリ名を変える場合は `vite.config.ts` の `base` も合わせて変更します。
